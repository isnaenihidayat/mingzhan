Create a reusable theme for the requested output, then apply it consistently.

1. Prefer the user's supplied theme or organization brand. Otherwise select a small palette and type hierarchy suited to the content and medium; do not impose the same appearance on every subject.
2. Define tokens for background, surface, text, muted text, border, accent, status colors, font families and heading/body sizes. Include chart series colors that remain distinguishable beyond color alone.
3. For HTML, use CSS custom properties and light/dark variants where requested or required by artifact-design. For DOCX/PPTX/XLSX/PDF, map tokens to native styles and explicit document sizes rather than copying CSS literally.
4. Check contrast, grayscale legibility, chart labels and long text. Preserve data and narrative when restyling; a theme change must not rewrite facts.
5. Save the theme with the requested deliverable or as a requested reusable profile artifact. Present a small number of concrete choices only when the user asks to compare themes.
