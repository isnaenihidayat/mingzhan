Create an original static design in the requested dimensions and output format.

1. Identify message, audience, destination and print/screen dimensions. Use supplied copy, imagery and identity. If content is missing, propose or clearly label draft copy instead of inventing factual claims.
2. Define hierarchy, typography, palette, grid and focal point. Prefer intentional composition with readable text over decorative effects. Respect image rights and avoid copying a particular artist's work.
3. Use SVG/HTML for vector-native compositions or an available image tool for raster work. For PNG export, use an available renderer; for printable PDF, use an assigned PDF workflow. Do not rename an SVG to PNG.
4. Check text spelling, margins, crop, contrast, image resolution and font availability. Keep an editable source when useful and requested.
5. Deliver the actual verified graphic and state any export or font limitation. Use save_artifact for text sources; binary output requires an available execution/export tool.
